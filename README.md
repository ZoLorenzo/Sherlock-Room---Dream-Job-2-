<h2>Description</h2>
Project write-up on investigating Lazaru Group's "Dream Job" operation. In order to understand the operation, custom-built malware had to be analyzed and intelligence needed to be gathered on the APT group. Open-Source tools were vital to solving this lab while utilizing an isolated environment (Windows 10 VM) for further procautions.
<br />


<h2>Tools and  Used</h2>

- <b>MITRE ATT&CK</b>
- <b>VirusTotal</b> 
- <b>Hybrid Analysis (Malware Anlysis powered by CrowdStrike Falcon Sandbox)</b>

<h2>Environments Used </h2>

- <b>Windows 10 VM</b> (21H2)
- <b>Crowdstrike Falcon Sandbox</b> (21H2)
